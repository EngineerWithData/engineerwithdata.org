Mission

Support data-driven engineering analysis and design.

Our members call themselves the Turtles. Slow and steady, one curated dataset at a time.

When we design a steel-framed building, we lean on semi-empirical equations like the column curve in AISC 360. Those equations trace back to models by Perry, Ayrton and Robertson and to physical tests run up to 1970.

Since then we have accumulated far more knowledge, measurements and simulation results. Most of it is scattered across technical reports and theses, and much of it is getting lost.

What would happen if we carefully curated historical and recent test data and offered it up with an easy, open interface?

Other fields show the payoff. The Worldwide Protein Data Bank has curated protein structures since 1971, and that archive made AlphaFold possible. Steel test data is sparse by comparison, so we couple data with theory and existing models to get the most from every test.

EngineerWithData is a volunteer working group of practitioners, researchers and students. We build open databases, publish them on GitHub, and develop the data-driven and AI models that use them.

  1. 01 · Intake

    Gather

    Find test programs in papers, reports and lab archives, and accept contributions from anyone.

  2. 02 · Curate

    Standardize

    Convert each dataset to a shared schema with units, geometry, material properties and citations.

  3. 03 · Host

    Publish

    Release the data openly on GitHub in CSV and JSON, with viewers and notebooks.

  4. 04 · Use

    Model

    Calibrate design equations, train ML and physics-informed models, and inform specification committees.

Models and initiatives

Putting the data to work.

AI agent

LLM agent for structural steel design

A prototype that generates framing layouts from plain-language descriptions, checks column strength with a physics-informed neural network, and writes and runs OpenSeesPy frame analyses.

View on GitHub →
Machine learning

Fastener backbone prediction

A neural network trained on the fastener database that predicts load-deformation backbones for cold-formed steel connections.

View on GitHub →
Analysis method

Instantaneous center method for diaphragms

Notebooks for inelastic shear strength of steel deck diaphragms with mixed fastener types, built on measured fastener behavior.

View on GitHub →
New initiative

Building databases with agents

AI agents that extract test data from published papers, with confidence scoring and manual checks so the curated values can be trusted.

New initiative

Code compliance database

Design codes stored as data: standardized variable names, BIM property mapping and equation logic in JSON, so any software can run the same transparent checks for AISC, ACI, ASCE or Eurocode.

Industry

A data-first steel industry

We advocate for an industry-led steel data advisory council to plan data intake, curation and open access, starting with the data behind AISC specification updates.
